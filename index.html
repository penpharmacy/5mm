🎓 ประวัติการสอบและใบประกาศนียบัตร

ข้อมูลถูกบันทึกไว้บนระบบคลาวด์ สามารถเข้าสู่ระบบจากเครื่องใดก็ได้เพื่อดูผลสอบและดาวน์โหลดใบประกาศนียบัตรย้อนหลัง

☁️ ระบบฐานข้อมูลคลาวด์ & ตัวตรวจสอบข้อมูล (Database Inspector)

ตรวจสอบแหล่งที่เก็บข้อมูล ดูตารางข้อมูลจริง และจัดการการซิงค์ข้ามอุปกรณ์

📍 ฐานข้อมูลถูกเก็บไว้ที่ไหน?

1. Google Cloud Firestore (ฐานข้อมูลหลักออนไลน์): เก็บแยกเป็น 4 ตารางหลัก ได้แก่ บัญชีผู้ใช้ (ce_users), ชุดข้อสอบ (ce_exams), รูปแบบใบประกาศฯ (ce_settings) และประวัติผลสอบ (ce_submissions) ซิงค์อัตโนมัติแบบเรียลไทม์

2. ไฟล์สำรอง JSON (กรณีนำโค้ดไปรันบนเซิร์ฟเวอร์ส่วนตัว): สามารถกดดาวน์โหลดเป็นไฟล์ .json เพื่อเปิดดูด้วยโปรแกรม Notepad/VS Code หรือนำไปอัปโหลดเข้าเครื่องอื่นได้ทันที
